# Quotidienn for Claude

Hooks [Quotidienn](https://quotidienn.com) up to Claude Code, so Claude can tell you when you've let a habit slide, start and stop your timers, and tell you what's left today.

```
/plugin install quotidienn --marketplace theowecker/quotidienn-claude
```

You'll need a key from your Quotidienn profile. More at [quotidienn.com/claude](https://quotidienn.com/claude).
